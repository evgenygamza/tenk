# Welcome screen

Introduces TenK on first launch. The primary action opens the empty Activities
state. Its add affordance currently previews an in-memory sample; issue #59 will
connect it to the first-activity form. Welcome shares the island background
with Activities and anchors the illustrated 10,000-hour Greek temple at the
summit. Copy and controls remain native Flutter widgets above the illustration.

Keep welcome-specific layout and behavior here. Reusable controls, including
the Liquid Glass button, live in `lib/ui/`.
